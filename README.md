## Development

This portfolio is intentionally built using a lightweight frontend stack rather than a large framework.

### Frontend

* Semantic HTML
* Modern CSS
* Vanilla JavaScript

### Design

The website uses a custom dark interface designed around the NOVA brand, with responsive layouts, subtle animations, and reusable components.

### Deployment

The website is deployed using Vercel and connected directly to the GitHub repository.

Changes pushed to the main branch can be automatically deployed to the live website.
